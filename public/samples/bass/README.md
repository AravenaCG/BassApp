# Real bass samples

Electric bass: Yamaha RBX recorded by Andrea Biasior, edited for FreePats by
Roberto. Source: https://github.com/freepats/electric-bass-YR (2019-09-30).
License: CC0-1.0, https://github.com/freepats/electric-bass-YR/blob/main/LICENSE.txt
Files: samples/finger/E.flac (MIDI 28), A.flac (33), D#.flac (39);
samples/pick/E.flac (28), A.flac (33), E2.flac (40).

Double bass: 1958 Otto Rubner, recorded by D. Smolken, 2013.
Source: https://github.com/sfzinstruments/dsmolken.double-bass
License: CC0-1.0, https://github.com/sfzinstruments/dsmolken.double-bass/blob/master/LICENSE
Files: pizz/pizz_g1_ma.wav (MIDI 31), pizz_d2_ma.wav (38), pizz_c3_ma.wav (48).
Original pitch roots verified against each bank's SFZ mapping, not file naming.

The bundled files are unchanged recordings (renamed locally). The browser adjusts
gain and uses the nearest recorded pitch with playback-rate transposition, including
low B on five-string bass; this is not a full multisampled commercial instrument.
No SFZ runtime, long releases, artificial room effect, delay or chorus are added.
Missing/unsupported recordings use the explicitly labelled clean synthesized fallback.
Finger is the default timbre, independently of the chosen fingering instrument.
The comparison is the same eight-note phrase at 80 BPM with the same volume control;
early RMS normalization is peak-limited, not a perceptual loudness guarantee.
