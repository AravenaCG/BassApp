# Arte del sendero

Recursos generados para Appbass con el generador de imágenes integrado y aprobados por el responsable del producto el 9 de octubre de 2026.

## Avatares

- `avatar-groove.png`: bajista con bajo eléctrico de cuatro cuerdas.
- `avatar-pulse.png`: bajista con bajo eléctrico de cinco cuerdas.
- `avatar-upright.png`: contrabajista.

Se generaron como personajes 2D completos, con fondo transparente, contorno neón y siluetas diferentes. El prompt tomó como referencia visual las láminas modulares aportadas por el usuario y pidió conservar el lenguaje oscuro, cian, violeta y magenta de Appbass, sin texto ni marcas.

## Mundos del recorrido

- `journey-basic.jpg`: cuarto, garage y primer bar.
- `journey-intermediate.jpg`: club, estudio y teatro.
- `journey-advanced.jpg`: festival, ciudad y estadio final.

Las variantes `journey-*-v2.jpg` corrigen la dirección narrativa para la navegación web: el punto inicial aparece arriba y el destino abajo, siguiendo el scroll natural de la página. Los originales se conservan como referencia del concepto aprobado.

Se generaron como fondos verticales continuos, sin personajes, texto, logotipos ni nodos interactivos. Los controles, nombres de lección y estados de avance se superponen en HTML para conservar accesibilidad y capacidad de edición.

Los originales se generaron a 1024 × 1536. Las copias incluidas aquí están optimizadas para web; los avatares conservan transparencia y los escenarios usan JPEG.
